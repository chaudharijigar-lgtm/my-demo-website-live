☀ On-Ground Display Tips
LED wall in sun → use LED Wall mode. Black background means unlit pixels, which gives the strongest contrast; yellow and white are the brightest colours an LED panel can show. Set panel brightness to 100% in daytime.
TV / monitor in sun → use Daylight TV mode. LCD screens reflect sunlight, so black text on white wins. Tilt the screen away from the sun and add a shade canopy if possible.
Far audience (20 m+) → use Big View. Every line is sized to the screen, readable at roughly 1 m of distance per 1 cm of letter height.
Running the screen → open the LED laptop's tab, click once, press F for fullscreen. The screen stays awake and the cursor hides itself. Change everything else from this control room tab in the same browser.
Evening session → switch to Night or set Auto so it changes by itself at sunset.

📱 Phone & Sync Setup — how referee QR codes work
Referee mode
Results entered in this browser appear on the LED tab straight away. Phones scanning a QR in this mode will not reach this laptop.
How it works: each QR code carries that event's athlete list, so the phone needs no login and no shared database. The referee enters results → taps Send on WhatsApp → the control room taps the link on this laptop (or pastes the code in Enter Results → Import) → the LED updates.
Needs: the page hosted online (step 1 below) so phones can open it. Re-print QR codes after changing athletes.
One-time setup (≈8 min, free):
1. Open console.firebase.google.com → Add project (any name, Analytics off).
2. Build → Authentication → Get started → Sign-in method → Anonymous → Enable.
3. Build → Realtime Database → Create database → location Singapore (asia-southeast1) → Start in locked mode.
4. Rules tab → delete everything → paste these rules → Publish.
5. Copy the database URL (ends in firebasedatabase.app) and, from ⚙ Project settings → General, the Web API key → paste both below → Connect.
Security: only this laptop can change the meet. Each referee QR can write results for its own event only. Spectators and screens can only read. The room code is the read password.
